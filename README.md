
# 🚀 FastAPI Task Manager

A RESTful Task Management API built using Python and FastAPI. This project allows users to create, retrieve, update and delete tasks through API endpoints.

## 🌟 Features

- Create new tasks
- Retrieve all tasks
- Retrieve individual tasks
- Update existing tasks
- Delete tasks
- Interactive API documentation using Swagger UI

## 🛠️ Technologies Used

- Python
- FastAPI
- Pydantic
- Uvicorn
- REST API

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Boddusai/task-manager.git
cd task-manager
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment

Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
uvicorn main:app --reload
```

## 📖 API Documentation
